📚 Library Management System

A console-based Library Management System developed in Java using Object-Oriented Programming (OOP) principles. This application allows users to manage books and members, search books, borrow and return books, and perform basic library operations through an interactive menu-driven interface.

🚀 Features
Add new books
Register new library members
Display all books
Display available books
Search books by title, author, or genre
Borrow books
Return books
Book availability validation
Menu-driven console interface
Encapsulation using private fields and public getters/setters
